# Agents

Não há agents ou subagentes ativos neste setup. Planejamento, implementação,
investigação e revisão acontecem na sessão principal do Pi.

O Pi Package oficial carrega extensions, skills, prompts e themes. Agents são um
recurso de extensões de subagentes, não do manifest principal do Pi. Caso agents
especializados voltem a ser necessários, suas definições podem ficar neste
diretório, mas a extensão escolhida deverá declarar ou descobrir o caminho
explicitamente.
